Mission 2

Contexte :

L’objectif de cette mission est de commencer à exploiter la base de données de l’entreprise KDou pour pouvoir par la suite avoir des analyses et indicateurs pertinents.

Introduction :

L’objectif de cette étude SQL était d’explorer et d’interroger différentes tables d’une base de données commerciale afin de :

  • Comprendre les relations entre clients, commandes, fournisseurs, produits et catégories
  • Réaliser des jointures
  • Filtrer les données
  • Identifier des cas particuliers (clients sans commande, fournisseurs sans produits…)

Chaque question (A → M) avait pour but de manipuler SQL à travers des requêtes d’exploration, de filtrage ou de jointures

Sources des données :

Les tables utilisées dans l'étude sont les suivantes :

  • Clientele
  • Commande
  • Fournisseur
  • Produit
  • Categorie

Ces tables ont été mobilisées individuellement ou combinées via différentes jointures.

Résultats :

Voici les principaux résultats obtenus parmi les questions A → M :

  1. Clients sans commande (Question G)

    2. SELECT c.CodeCli, c.Societe, c.MailCli
    FROM Clientele AS c LEFT JOIN Commande AS cm
    ON c.CodeCli = cm.CodeCli
    WHERE cm.[N° commande] IS NULL
    ORDER BY 1;

    Grâce à un LEFT JOIN, nous avons identifié les clients n’ayant jamais passé de commande.

  2. Fournisseurs sans produit (Question J & K)

    3. SELECT f.NoFour, f.Societe
    FROM Fournisseur AS f LEFT JOIN Produit AS p
    ON f.NoFour = p.NoFour
    WHERE p.RefProd IS NULL
    ORDER BY 1;

    Les LEFT JOIN ont permis de repérer les fournisseurs n’ayant aucun article enregistré dans la table Produit.

  3. Catégories provenant des États-Unis (Question H)

    4. SELECT DISTINCT C.NomCateg
    FROM (Categorie AS C INNER JOIN Produit AS P
    ON C.CodeCateg = P.CodeCateg) INNER JOIN Fournisseur AS F
    ON P.NoFour = F.NoFour
    WHERE F.Pays = "Etats-Unis" OR F.Pays = "U.S.A."
    ORDER BY 1;

    La doubles jointures a permis d’extraire uniquement les catégories associées à des fournisseurs américains.

    Résultat question H
    Nom catégorie
    Boissons
    Condiments
  4. Couples de clients situés à Paris (Question L)

    5. SELECT C1.CodeCli, C1.Societe, C1.MailCli, C2.CodeCli, C2.Societe, C2.MailCli
    FROM Clientele AS C1 INNER JOIN Clientele AS C2
    ON C1.CodeCli > C2.CodeCli
    WHERE C1.Ville = 'Paris" AND C2.Ville = 'Paris"
    ORDER BY 1, 4;

    Jointure sur la même table (auto-jointure).
